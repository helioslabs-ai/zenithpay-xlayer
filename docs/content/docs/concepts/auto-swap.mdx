---
title: Auto-Swap (Deprecated)
description: Auto-swap is no longer needed on Base
---

> **Note:** Auto-swap has been removed in the Base migration. On the previous X Layer deployment, ZenithPay could automatically swap OKB to USDG when the agent had insufficient settlement token balance. This feature is no longer needed.

## Why auto-swap was removed

On Base, the settlement token is USDC — a widely held stablecoin. Agents are expected to hold USDC directly in their Privy-managed wallets. The complexity of an auto-swap layer (native token -> stablecoin) is not justified when:

- USDC is natively available and widely bridged on Base
- Agent wallets can be funded directly with USDC
- Removing the swap step simplifies the payment flow and reduces failure modes

## Current payment flow

1. SpendPolicy check (USDC amount)
2. USDC balance check
3. x402 `/verify` -> `/settle` on Base
4. Ledger entry written

If the agent has insufficient USDC, the payment is blocked with `insufficient_balance`. The operator should fund the agent wallet with USDC on Base.
