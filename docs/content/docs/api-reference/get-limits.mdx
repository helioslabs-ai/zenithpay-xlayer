---
title: GET /limits
description: Read active spend policy per agent
---

## Endpoint

```text
GET https://zp-api-q4hd.onrender.com/limits
```

## Auth

Bearer API key required.

## Request

- Optional query: `address=0x...`
- Optional header: `X-Owner-Address: 0x...`

## Response shape

```json
{
  "agents": [
    {
      "address": "0x...",
      "perTxLimit": "0.25",
      "dailyBudget": "3.00",
      "allowlist": ["exa.ai", "firecrawl.dev"],
      "approvalThreshold": "0.10",
			"policyContract": "0x..."
    }
  ]
}
```
