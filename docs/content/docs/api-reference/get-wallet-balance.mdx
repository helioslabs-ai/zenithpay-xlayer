---
title: GET /wallet/balance
description: Get USDC/ETH balances and remaining budget per linked agent
---

## Endpoint

```text
GET https://api.usezenithpay.xyz/wallet/balance
```

## Auth

Bearer API key required.

## Request

- Optional query: `address=0x...`
- Optional header: `X-Owner-Address: 0x...`

## Response shape

```json
{
  "agents": [
    {
      "agentAddress": "0x...",
			"usdcBalance": "12.50",
			"ethBalance": "0.01",
      "remainingDailyBudget": "1.75"
    }
  ]
}
```

Settlement token is USDC on Base (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`).
